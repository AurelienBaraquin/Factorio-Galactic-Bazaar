# Lessons

Mistakes made on this project (by a person or an AI agent) and what now prevents them. Read it
before starting work; add to it whenever review, CI or the user catches something.

Each entry: `YYYY-MM-DD — what went wrong — how it was caught — what now prevents it`.
"What now prevents it" must be concrete: a test, a lint rule, a hook, a rule in `CLAUDE.md`, a
check in CI. An entry with no prevention is an open problem; say so.

2026-10-29 — A "vanilla" headless load check silently ran with Space Age, because the headless build enables its bundled DLC mods when `mod-list.json` does not mention them — caught by reading which mods the log loaded — the `factorio-tooling` skill and `README.md` now require listing `space-age`, `quality`, `elevated-rails` and `recycler` as disabled for vanilla runs; an automated check comes with the test setup (#4).
2026-10-29 — The first in-game save/reload test used FactorioTest's `.after_reload_script`, copied from the tooling skill; for a mod it calls `game.reload_script`, which only reloads the scenario script, so the run aborted ("Reload was requested but did not happen") — caught by the first real FactorioTest run — the skill, the reference and both Factorio agents now prescribe `.after_reload_mods`, and the `game` CI job runs the test on every PR.
2026-10-29 — Merging the M0 stack (#32→#38) with `--delete-branch` made GitHub close #34 instead of retargeting it, and the later `gh pr edit --base main` did not take, so #35–#38 merged into their parent branches, not `main` — caught by checking `origin/main` after the merges — fixed with one integration PR (#39); from now on, before merging a stacked PR, check `gh pr view <n> --json baseRefName` says `main`, merge without `--delete-branch`, and delete branches only once `git merge-base --is-ancestor <branch> origin/main` holds for each.
2026-10-29 — The first base-value algorithm (fixed-point iteration with an equal cost split) let loops leak value (a cut-and-weld loop priced a plate at 0.03 instead of 1.32), let Fulgora's scrap recycling be excluded as "recycling", and its unpriced log hid items — caught by the `factorio-mod-reviewer` agent before merge — the valuation now refuses offers that go through the key itself (ancestor guard), recycling is only excluded when it is the sole category, the unpriced list comes from every tradeable item, and `spec/core/valuation_spec.lua` covers the leak loop, barrel round trip, bulk path and tier order.
2026-10-29 — A commit on the technology branch went in with two luacheck warnings, because the pre-commit hook only ran the documentation check — caught when merging the pricing fixes forward — `.githooks/pre-commit` now also runs luacheck and busted when the local toolchain is installed.
2026-10-30 — Twice (cargo, market window), an in-game test's `after_each` crashed or wrote `nil` into storage after an `.after_reload_mods` step, because reloading re-runs the test file and resets its locals — caught by the FactorioTest runs — tests with a reload step re-fetch what they need in `after_each` and guard values captured before the reload; the `factorio-tooling` skill now says so.
2026-10-30 — The orbital-capsule branch added `storage.freight` without bumping the mod version, so a save made on `main` would skip `on_configuration_changed` and crash on the first unload tick — caught by the `factorio-mod-reviewer` agent — a change that adds or reshapes `storage` now bumps `info.json` and `changelog.txt` in the same change (or adds a migration), as `docs/data-model.md` requires; no automated check yet.
2026-10-30 — An export chest whose hub was destroyed lost its attachment for good when an export tick ran before `on_object_destroyed` and no powered hub was in range, because `cargo.powered_hub` stored the failed powered-only search — caught when new in-game tests shifted the tick timing of `tests/cargo.lua` — `powered_hub` now falls back to the nearest hub, and `tests/cargo.lua` runs an export between the destroy and its event.
2026-10-30 — Three play-test deploys were reported done while `tools/build.py deploy` had been called without the mods folder and exited 1 with its usage text, hidden behind `| tail -1` — caught when checking the deployed `info.json` — deploys are run with the folder (`tools/build.py deploy /mnt/c/Users/aurel/AppData/Roaming/Factorio/mods`) and confirmed by reading the deployed `info.json` version; never pipe a command whose exit code is the result.
2026-10-30 — The first value-override version let a `nil` number through the remote checks (a later rebuild would crash every load), kept market displacement in units when a base value changed (a 100× multiplier made goods free), and let a factor turn a natural source into a main-tier one — caught by the `factorio-mod-reviewer` agent — numbers are now required and bounded, entries validated on rebuild, `market.rebase_all` runs after every rebuild, fixed values carry their tier; `tests/overrides.lua` and the specs cover nil, bounds, factor 1 and rebasing.
2026-10-30 — The first quality pricing gave each quality market the same depth in credits, so a legendary item (value ×243) had 243 times fewer units of liquidity and export chests could not sell most legendary items; the window's Sell also sold every quality against a normal-quality preview — caught by the `factorio-mod-reviewer` agent — quality markets scale `depth_credits` with their value ratio, the window sells normal quality only, and `tests/quality.lua` checks a legendary processing unit is as sellable as a normal one.
2026-10-30 — The first power substations trusted the electric-energy-interface's own settings (a blueprint or mod setting `power_production` would have made credits from nothing), priced electricity at a boiler's efficiency although Space Age's heating tower reaches 2.5, searched for a hub per substation at every settlement, and flushed the journal every few minutes — caught by the `factorio-mod-reviewer` agent — settings are zeroed on build and at each settlement, the efficiency is read from the prototypes, substations attach to hubs on events, recurring trades merge their journal entries; `tests/power.lua` covers each.
2026-10-30 — The first price combinators could be registered twice (a later removal would crash the game), walked a key list that a remote override could replace mid-build, trusted sections a blueprint or paste could change, promised a 10 s refresh that more than 16 combinators could not keep, and stated an averaged budget that hid the costly pass — caught by the `factorio-mod-reviewer` agent — registration is idempotent, builders capture their lists, foreign sections are replaced, the balance has its own live slot, freshness and the worst pass are documented and measured; `tests/price_signals.lua` covers each.
2026-10-30 — The first order combinator read its budget from `gb-credits`, the signal price combinators emit the balance on, so wiring one in by mistake turned every price into an order with no cap; its budget was per combinator, so N combinators spent N budgets; and the guide's decider example relied on a constant output the 2.x GUI may not offer — caught by the `factorio-mod-reviewer` agent — the budget is a signal of its own, required, shared per force, an input carrying `gb-credits` is refused, and the example uses input counts; `tests/circuit_orders.lua` covers each.
2026-10-30 — The telecommunications change hid the trend cells of the market window's table below level 2, which would likely shift every later cell into the wrong column (a hidden table child gives up its slot), kept a price feed across base value rebuilds, and gave no budget for price combinators rebuilding every 2 s — caught by the `factorio-mod-reviewer` agent — table cells are emptied instead of hidden (`tests/telecom.lua` checks they stay visible), the feed is cleared on rebuild, and the level-2 cost is measured and documented.
2026-10-30 — Spoilable goods (Space Age) could never be sold, because in 2.1 every stack of a spoilable item carries a `LuaItem` and `cargo.lua` read any `LuaItem` as "extra data"; the issue (#56) even assumed the opposite — caught by the first in-game test that sold one under `--mods space-age` — `tests/cargo.lua` now sells spoilable stacks in the Space Age run; check an API property empirically in a test before relying on what it "should" return.
2026-10-30 — Deleting `feat/11-quality-values` after merging #55 made GitHub close #57, which another session had stacked on it, although the stacked-merge lesson above already warned of this — caught when checking on that session — before deleting a merged branch, run `gh pr list --base <branch>` and retarget every open PR to `main` first (`gh api -X PATCH repos/{owner}/{repo}/pulls/<n> -f base=main`); the replacement PR is #62.
2026-10-30 — The first fluid manifolds accepted a fluid order whenever an import manifold existed, so a fluid capsule whose manifold held another fluid could never land and, since unloading stopped at the first capsule that did not fit, blocked every capsule behind it; the export also sold before removing the fluid and scanned every manifold per delivery — caught by the `factorio-mod-reviewer` agent — orders check a manifold can take the fluid, unloading no longer holds back other capsules (ADR-0006 amended), fluid leaves the tank before the sale, imports are indexed per hub and exports batched; `tests/manifold.lua` covers each.
2026-10-30 — The first logistics tiers shared one launch schedule and one queue bound per hub, so a teleporter shipment waited behind capsules and the arrival shown was wrong, and upgrading to the teleporter (smaller bound) refused every order; the window could also charge another tier's fee than the one it showed — caught by the `factorio-mod-reviewer` agent — each tier has its own launches and bound, unloading takes every landed shipment, and the window's purchase names the tier it showed; `tests/freight.lua` covers each.
2026-10-30 — The first docking bay let the market window show the shuttle for a hub with fuel for one shipment and then refuse a larger order as 'tier changed', refused an order when the best tier's queue was full instead of falling back, and read the tier by scanning every bay in the world (0.34 ms) — caught by the `factorio-mod-reviewer` agent — the window plans the tier for the quantity typed, a full queue falls back too, bays are indexed per hub and fuel counting stops once enough (0.06 ms); `tests/docking_bay.lua` covers each.
2026-10-30 — The first teleporter replaced the base energy source without an input limit, so it took its whole missing buffer every tick and stayed 'powered' on a network far too weak for it; its power test never connected it to a network — caught by the `factorio-mod-reviewer` agent — the intake is capped at 24 MW and `tests/teleporter.lua` feeds it from a real generator, strong and weak; an electric-energy-interface whose energy source is replaced must state its flow limits.
2026-10-30 — The first catapult's hidden capacitor kept the base interface's health, so area damage could kill it and silently stop the catapult for good, an area clone left an orphan copy, and its 2×2 collision box let poles power the 1×1 catapult from too far — caught by the `factorio-mod-reviewer` agent — the capacitor is indestructible, not repairable, sized like the catapult, adopted when already present and recreated lazily; hidden helper entities must be made indestructible and clone-safe.
2026-10-30 — The first contract engine capped a failed contract's penalty at the force's balance, so a force could spend everything before the deadline and pay nothing; it also renumbered contracts on force merge, let repeated or quality-less goods keys make a contract easier, accepted offers that never expire and deliveries after the deadline — caught by the `factorio-mod-reviewer` agent — the guarantee held on acceptance is deposit plus penalty, ids are unique across forces, specs are validated and copied, deliveries carry their tick; `spec/core/contracts_spec.lua` covers each.
2026-10-30 — The first incoming contracts shipped the ingredients before the engine checked the offer's end, so an offer accepted in the last second of its 60-tick settlement gap gave the ingredients free; priced the guarantee from base values although market prices can sell above them; paid a reward even when buying the products and selling the ingredients was profitable; and could hide contracts beyond the window's 8 rows — caught by the `factorio-mod-reviewer` agent — every acceptance check (`contracts.can_accept`) runs before shipping, the penalty rises to the market price at acceptance, the reward is capped by the value crafting adds, open contracts are capped at the window's rows; `tests/incoming_contracts.lua` and the specs cover each. A side effect that cannot be undone runs only after every check of the step that follows it.
