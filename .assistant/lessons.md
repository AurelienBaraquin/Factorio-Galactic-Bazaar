# Lessons

Mistakes made on this project (by a person or an AI agent) and what now prevents them. Read it
before starting work; add to it whenever review, CI or the user catches something.

Each entry: `YYYY-MM-DD — what went wrong — how it was caught — what now prevents it`.
"What now prevents it" must be concrete: a test, a lint rule, a hook, a rule in `CLAUDE.md`, a
check in CI. An entry with no prevention is an open problem; say so.

2026-10-29 — A "vanilla" headless load check silently ran with Space Age, because the headless build enables its bundled DLC mods when `mod-list.json` does not mention them — caught by reading which mods the log loaded — the `factorio-tooling` skill and `README.md` now require listing `space-age`, `quality`, `elevated-rails` and `recycler` as disabled for vanilla runs; an automated check comes with the test setup (#4).
2026-10-29 — The first in-game save/reload test used FactorioTest's `.after_reload_script`, copied from the tooling skill; for a mod it calls `game.reload_script`, which only reloads the scenario script, so the run aborted ("Reload was requested but did not happen") — caught by the first real FactorioTest run — the skill, the reference and both Factorio agents now prescribe `.after_reload_mods`, and the `game` CI job runs the test on every PR.
2026-10-29 — Merging the M0 stack (#32→#38) with `--delete-branch` made GitHub close #34 instead of retargeting it, and the later `gh pr edit --base main` did not take, so #35–#38 merged into their parent branches, not `main` — caught by checking `origin/main` after the merges — fixed with one integration PR (#39); from now on, before merging a stacked PR, check `gh pr view <n> --json baseRefName` says `main`, merge without `--delete-branch`, and delete branches only once `git merge-base --is-ancestor <branch> origin/main` holds for each.
2026-10-29 — The first base-value algorithm (fixed-point iteration with an equal cost split) let loops leak value (a cut-and-weld loop priced a plate at 0.03 instead of 1.32), let Fulgora's scrap recycling be excluded as "recycling", and its unpriced log hid items — caught by the `factorio-mod-reviewer` agent before merge — the valuation now refuses offers that go through the key itself (ancestor guard), recycling is only excluded when it is the sole category, the unpriced list comes from every tradeable item, and `spec/core/valuation_spec.lua` covers the leak loop, barrel round trip, bulk path and tier order.
2026-10-29 — A commit on the technology branch went in with two luacheck warnings, because the pre-commit hook only ran the documentation check — caught when merging the pricing fixes forward — `.githooks/pre-commit` now also runs luacheck and busted when the local toolchain is installed.
2026-10-30 — Twice (cargo, market window), an in-game test's `after_each` crashed or wrote `nil` into storage after an `.after_reload_mods` step, because reloading re-runs the test file and resets its locals — caught by the FactorioTest runs — tests with a reload step re-fetch what they need in `after_each` and guard values captured before the reload; the `factorio-tooling` skill now says so.
2026-10-30 — The orbital-capsule branch added `storage.freight` without bumping the mod version, so a save made on `main` would skip `on_configuration_changed` and crash on the first unload tick — caught by the `factorio-mod-reviewer` agent — a change that adds or reshapes `storage` now bumps `info.json` and `changelog.txt` in the same change (or adds a migration), as `docs/data-model.md` requires; no automated check yet.
2026-10-30 — An export chest whose hub was destroyed lost its attachment for good when an export tick ran before `on_object_destroyed` and no powered hub was in range, because `cargo.powered_hub` stored the failed powered-only search — caught when new in-game tests shifted the tick timing of `tests/cargo.lua` — `powered_hub` now falls back to the nearest hub, and `tests/cargo.lua` runs an export between the destroy and its event.
2026-10-30 — Three play-test deploys were reported done while `tools/build.py deploy` had been called without the mods folder and exited 1 with its usage text, hidden behind `| tail -1` — caught when checking the deployed `info.json` — deploys are run with the folder (`tools/build.py deploy /mnt/c/Users/aurel/AppData/Roaming/Factorio/mods`) and confirmed by reading the deployed `info.json` version; never pipe a command whose exit code is the result.
2026-10-30 — The first value-override version let a `nil` number through the remote checks (a later rebuild would crash every load), kept market displacement in units when a base value changed (a 100× multiplier made goods free), and let a factor turn a natural source into a main-tier one — caught by the `factorio-mod-reviewer` agent — numbers are now required and bounded, entries validated on rebuild, `market.rebase_all` runs after every rebuild, fixed values carry their tier; `tests/overrides.lua` and the specs cover nil, bounds, factor 1 and rebasing.
2026-10-30 — The first quality pricing gave each quality market the same depth in credits, so a legendary item (value ×243) had 243 times fewer units of liquidity and export chests could not sell most legendary items; the window's Sell also sold every quality against a normal-quality preview — caught by the `factorio-mod-reviewer` agent — quality markets scale `depth_credits` with their value ratio, the window sells normal quality only, and `tests/quality.lua` checks a legendary processing unit is as sellable as a normal one.
